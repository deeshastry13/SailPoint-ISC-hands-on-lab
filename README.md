# SailPoint ISC Hands-On Lab

A practical hands-on lab documenting SailPoint Identity Security Cloud (ISC) implementation, application onboarding, connectors, 
identity lifecycle, provisioning, access governance, and troubleshooting.

## Purpose

This repository documents practical SailPoint ISC implementation activities and configuration walkthroughs based on hands-on lab exercises.

The objective is to build a reusable reference for understanding how SailPoint ISC connects with enterprise applications and manages identities, 
accounts, entitlements, access, and lifecycle processes.

## Planned Topics

More SailPoint ISC implementation topics will be added progressively, including:

- Application onboarding
- Identity Profiles
- Identity correlation
- Joiner-Mover-Leaver (JML)
- Workflows
- Access Profiles
- Roles and RBAC
- Access Reviews
- Provisioning
- Connector troubleshooting
- Virtual Appliance troubleshooting
- Identity lifecycle management

## Disclaimer
This repository is intended for learning, hands-on practice, technical reference, and demonstration purposes.
Environment-specific configurations, credentials, secrets, and sensitive information are excluded from the documentation.
